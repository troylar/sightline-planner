Your team's work, in plain sight.

Open the ready-to-use app in Chrome or Edge. The current version appears next to What's new.

Open Sightline

Your plan is a separate JSON or YAML file. In the app, choose File → Open shared plan… and select your plan. A plan link alone does not load that file.

If the app is missing, run ./build.sh from this repository, then open it again. The file under src/ is the development template.

If you have unsaved work in another tab, keep that tab open and use File → Download JSON there before switching copies.
